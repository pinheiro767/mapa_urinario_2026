# NeuroMapa Urinário — Edição Anime 2.0

Aplicativo PWA de Anatomia Clínica, com **55 missões baseadas na Taxonomia de Bloom**, nove ramos interativos e três personagens anime (Mika, Dra. Yumi e Kai).

## Novidades do visual

- Tela inicial com a ilustração original do laboratório e personagens, adaptada sem recorte no celular.
- Mapa mental holográfico interativo com os nove ramos do sistema urinário: no computador, selecione os cartões da imagem; no celular, selecione os ramos nos cartões acessíveis abaixo da imagem integral.
- Retratos anime individuais nos diálogos; personagem em destaque muda a cada fala.
- O PWA usa as imagens fornecidas pela autora, otimizadas em WebP.

## Instalação / GitHub Pages

1. Extraia todo o conteúdo do ZIP na raiz de um repositório público do GitHub.
2. No GitHub, abra **Settings > Pages > Deploy from a branch > main / (root)**.
3. Abra o link HTTPS publicado; no celular, escolha **Adicionar à tela inicial / Instalar app**.
4. Faça uma primeira visita com internet para carregar os arquivos e liberar o uso offline.

**Arquivos:** index.html, app.js, cases.js, style.css, manifest.webmanifest, sw.js e diretório assets/.

**Sobre os dados:** o progresso e as sínteses ficam no localStorage do dispositivo; exporte seu progresso em Meu Caderno para fazer backup. O progresso não é sincronizado automaticamente entre aparelhos. Conteúdo educacional, não é instrumento diagnóstico.
